# 软测量与闭环控制准入规范

本工程把结论分为三级：离线候选模型、软测量候选、闭环控制候选。低一级通过不能替代高一级评审，`R²` 高也不能单独作为上线依据。

## 数据提交要求

- 使用真实连续时序，保留原始时间戳、采样周期、单位、质量码、设备和工况标识。
- 指明主输出的化验或仪表方法、采样与报告延迟、检出限、校准记录及坏值规则。
- 标明操纵量、扰动量、状态量和被控量；字段语义不能通过改名伪造。
- 单独冻结跨时间或跨工况外部验证集；不得参与字段筛选、清洗阈值、阶次或参数选择。
- 清洗只允许因果处理。输出缺失和异常保留为空，不用未来值插补训练或评估真值。

## 软测量候选门槛

必须通过字段完整性、数据质量、独立测试、持续值基线、稳定性、多步预测、自由仿真、残差白噪声与输入残差独立性检查。还必须完成外部工况验证、量测可追溯性、输入越界和漂移监测、失效回退及影子运行。

## 闭环控制候选附加门槛

必须确认操纵量到输出的因果方向和有效时滞，记录控制约束、变化率、联锁独立性、异常回退和人工接管方案。先做影子运行，再经仿真或测试环境、限幅闭环和分阶段投运；最终批准由工艺、自控、安全和运行责任人签署。

流水线输出 `deployment_readiness`，逐门给出通过状态和缺失证据。工程不会把普通离线模型自动标记为可上线或可闭环。
