# A14 真实工业数据候选与使用边界

核验日期：2026-09-11

## 结论

当前公开渠道中，没有找到可直接下载、字段完整且能够证明来自钢厂步进梁式加热炉现场的多变量动态过程数据。已有论文证明这类真实数据存在，但原始数据通常因企业保密只支持联系作者申请。

当前最适合 A14 全流程演示的公开数据是 **Process data collected by blast-furnace sensors**。它来自真实钢铁高炉，不是仿真数据；但设备是高炉，不是当前界面文案中的步进梁式加热炉。答辩时必须按真实场景表述，不能把它称为加热炉数据。

## 与 A14 功能的对应关系

| A14 能力 | 数据中的可验证任务 |
| --- | --- |
| 异常值识别与清洗 | 对原始过程数据做范围、突变、孤立点和冻结值检查；用第二数据集的炉况标签做旁证 |
| 高信噪比动态段提取 | 从鼓风量、富氧量、矿焦比变化中识别激励段，以硅含量响应和温度响应评价动态质量 |
| 时滞分析与补偿 | 过程量每小时采样，硅含量约 30–130 分钟不规则采样；先做多速率对齐，再估计纯滞后 |
| 共线性诊断与消减 | 热风压力与冷风压力相关系数约 0.995；多个炉顶/周边温度也高度相关 |
| 系统辨识 | 可建立“鼓风/富氧/矿焦比/压力/温度 → 铁水硅含量”软测量或动态预测模型 |
| 闭环寻优 | 以验证集 R²、RMSE、白噪声检验、数据覆盖率为目标，反向优化对齐、滞后、筛段和变量选择参数 |

## 推荐演示口径

“系统当前已接入公开可追溯的真实钢铁高炉历史数据。原始过程量来自 26 个现场传感器，铁水硅含量来自工厂实验室。数据存在多速率采样、强共线性和过程时滞，正好用于验证 A14 的数据规整、动态优选、时滞补偿、共线性处理、系统辨识和闭环寻优。当前钢厂加热炉页面中的合成数据只用于可控压力测试，不冒充真实生产数据。”

## 其他候选

1. **钢厂步进梁式加热炉论文数据**：场景完全一致，但公开论文的数据可用性声明为“联系通讯作者合理申请”，不适合作为马上可复现的数据源。
2. **University of Strathclyde 炉窑过程数据**：2022-09-06 至 2022-10-14，含原始 CSV、清洗后的数据和传感器说明，CC BY 4.0。来自工业燃气炉研究设施，炉窑类型相近，但不是钢厂步进梁式加热炉。
3. **UCI Steel Industry Energy Consumption**：真实钢铁企业数据，35,040 行、15 分钟采样、CC BY 4.0，但主要是用电与功率因数，缺少炉温和燃气等 APC 关键变量。
4. **UCI Gas Turbine CO and NOx Emission**：真实燃机电厂数据，36,733 行、11 个传感量、CC BY 4.0。许可和出处清楚，但数据按小时聚合，动态辨识能力弱于高炉数据。

## 仍需完成的工程工作

- 原始文件保持只读，另外生成适配系统上传接口的 CSV，不覆盖源文件。
- 为高炉场景建立字段角色映射、单位字典和物理范围配置。
- 明确多速率对齐策略；不能把实验室 Si 值简单向前填充后称为原始测量。
- 按时间顺序划分训练、验证、锁定测试集，禁止随机打乱造成数据泄漏。
- 在界面和报告中展示数据 DOI、许可、原始文件哈希和派生处理记录。
